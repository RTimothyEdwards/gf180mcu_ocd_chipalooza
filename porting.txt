Porting the Chipalooza harness chip from IHP SG13CMOS5L to GF180MCU
-------------------------------------------------------------------
This will start with a stupid-simple transfer of files with string
substitutions.

The following substitutions should be made everywhere, applied in
the correct order (substrings that match the beginnings of longer
strings should be applied later):

WARNING: these are SUBSTRING substitutions with no word boundary, so
the numeric rules at the bottom (3v3/1v2, 3.3/5.0, 1.2/3.3) also fire
INSIDE longer numbers.  1.25 became 3.35 in the bandgap tempco
denominator, and a whole 1.204..1.295 trim table in the bandgap
Verilog became 3.304..3.395.  The damage is hard to spot because the
result is still a plausible-looking number.  After running
port_from_ihp.py, run scripts/find_subst_damage.py, which pairs each
ported file with its IHP original and reports literals that differ by
exactly one of these rules applied to a prefix.
